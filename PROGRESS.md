## Phase 0: Setup - done

- Next.js 16.4 (App Router, Turbopack, Cache Components on by default) + TypeScript + Tailwind CSS 4.
- ESLint (flat config from create-next-app), Vitest 5, lucide-react.
- Font: Atkinson Hyperlegible Next via `next/font/google` (self-hosted at build time).
- Product name lives in `lib/config.ts` (`APP_NAME`), with the default emergency number and disclaimer line.
